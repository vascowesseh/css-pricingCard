# Pricing Cards | HTML & CSS

A responsive SaaS pricing page built with HTML5 and CSS3, featuring three subscription plans, modern card designs, and a customer testimonial section.

This project is part of my frontend development journey as I continue building my skills and working toward becoming a software engineer.

## About the Project

The goal of this project was to practice building a responsive pricing page similar to those used by modern SaaS companies.

The website allows visitors to compare three subscription plans:

- **Free Plan — $0/month:** Designed for learning and personal projects.
- **Pro Plan — $19/month:** Designed for developers building and shipping products.
- **Team Plan — $49/month:** Designed for growing teams that need collaboration features.

The Pro Plan is visually highlighted with a "Most Popular" badge.

This is a frontend design project. The subscription buttons are not connected to a payment system.

## Technologies Used

- **HTML5** — Page structure and content
- **CSS3** — Styling, layouts, animations, and responsive design
- **Font Awesome** — Icons for pricing plans and feature lists

No JavaScript or frontend frameworks were used.

## Features

- Three subscription pricing cards
- Responsive CSS Grid layout
- Highlighted Pro Plan with a "Most Popular" badge
- Feature comparison lists with checkmarks
- Disabled features displayed with different styling
- CSS gradient colors and custom properties
- Hover effects and smooth transitions
- Customer testimonial section with a profile image
- Responsive layouts for desktop, tablet, and mobile screens

## What I Practiced

While building this project, I practiced:

- Creating reusable CSS classes
- Using CSS Grid for multi-column layouts
- Using Flexbox to align elements
- Working with CSS custom properties (`:root`)
- Styling buttons, cards, borders, and shadows
- Creating gradient backgrounds and text
- Using relative and absolute positioning
- Adding hover effects with CSS transitions
- Writing media queries for responsive layouts
- Integrating Font Awesome icons
- Organizing HTML and CSS into separate files

## Responsive Design

The pricing cards adapt to different screen sizes using CSS media queries.

- **Desktop:** Three pricing cards displayed side by side
- **Tablet:** Two-column layout
- **Mobile:** Single-column layout with adjusted spacing and typography

Additional styling adjustments are included for smaller mobile screens.

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.

An internet connection is required to load the external Font Awesome icons and testimonial profile image.
